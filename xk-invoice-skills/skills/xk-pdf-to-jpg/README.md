# xk-pdf-to-jpg 使用说明与设计文档

PDF 批量转 JPG。这是全链路的**最前端**，把发票 PDF 转成可供视觉识别、归档的图片。

## 一、做什么

递归遍历目录下所有子目录的 PDF，用 **PyMuPDF** 渲染成 JPG，每个 PDF 输出到**它所在子目录的 `tu/`** 目录。

## 二、用法

```bash
python3 pdf2jpg.py <根目录> [缩放倍数]
```

- `<根目录>`：要处理的目录，递归遍历所有子目录。
- `[缩放倍数]`：默认 2.0（144 DPI），输出像素 = PDF Point 尺寸 × 2。
- 自动跳过名为 `tu` 的目录，避免重复处理。

## 三、为什么必须用 PyMuPDF

| 工具 | 结果 |
|---|---|
| **PyMuPDF（fitz）** ✅ | 正确栅格化矢量文字型 PDF，尺寸一致、不空白 |
| sips ❌ | 只做预览级栅格化，文字型矢量 PDF（滴滴电子发票等）渲染成**空白图** |
| qlmanage ❌ | 本机沙箱下不可用（sandbox initialization failed） |

## 四、自检（关键）

转换后必须检查空白图。空白图特征：文件 < 10KB；正常发票图 > 100KB。

```bash
find <根目录> -path '*/tu/*.jpg' -exec stat -f%z {} \; -print | sort -n | head
```

## 五、输出约定

- 文件名：沿用原 PDF 名（去 `.pdf`/`.PDF` 后缀）。
- 尺寸：不同 PDF 原始尺寸不同，输出尺寸也不同（这是正确行为，不是「不统一」）。

## 六、常见坑

- **机票行程单超大图**：转出来可能 6900×4006，视觉识别前需 `sips -Z 1600` 缩小（这一步在识别环节做，不在本脚本）。
- **`.PDF` 大写后缀**：脚本用 `.lower()` 判断，两种都能识别。

## 七、如何修改迭代

| 要改什么 | 改哪里 |
|---|---|
| 缩放倍数默认值 | `main()` 里 `zoom` 默认 2.0 |
| 输出目录名（tu） | `main()` 里 `tu_dir` 拼接 |
| 支持更多格式 | `main()` 里 `name.lower().endswith('.pdf')` 判断 |
