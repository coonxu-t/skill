# 按报销口径生成发票台账

## 这个技能做什么

把一批发票（含非增值税凭证）按**报销科目**归类，生成一份可交财务的 Excel 台账：

- **Sheet1「报销汇总」**：按报销科目分组，每类张数 + 金额，底部合计。
- **Sheet2「发票明细」**：全部明细，含「报销科目」列，已开启筛选、冻结表头。

金额全程用 `Decimal` 累加，避免浮点误差；合计值直接写入静态数值（不依赖公式重算），任何预览器都能正确显示。

**支持目录遍历**：脚本可用 `--scan <目录>` 模式递归扫描各子目录的 `tu` 图片，自动统计每子目录图片数，并与数据条数做交叉校验（图片总数 vs 数据条数是否一致），及时发现「遗漏」或「多计」。

**支持按科目归档图片**：另有一个 `organize_invoices.py`，按报销科目把目录下所有发票图片**拷贝**到 `invoice/<科目>/` 子目录，方便交付财务或归档。

## 何时使用

- 用户说「按报销口径重新分类」「生成报销台账」「出报销汇总表」
- 已有一批发票识别结果，要按费用科目归类汇总
- 把发票、火车票、滴滴、机票行程单、停车费非税票据等统一整理成报销 Excel

**上游依赖**：本技能不负责 OCR 识别发票字段。识别发票请用 `xk-invoice-ocr-summary`；PDF 转图片请用 `xk-pdf-to-jpg`。本技能只做「归类 + 出表」。

## 报销科目归类规则

| 报销科目 | 判定依据（发票内容标签） |
|---|---|
| 餐饮费 | `*餐饮服务*`、`*餐费*`、`*餐饮*`、`奶茶`、`饮品` |
| 住宿费 | `住宿费`、`住宿服务`（通常是增值税专用发票） |
| 交通费-火车票 | `*铁路客运*电子客票`、`退票费` |
| 交通费-网约车 | `*交通运输服务*客运服务费`（滴滴等） |
| 交通费-机票 | `航空运输`、`行程单`、`机票`、`旅游服务` |
| 图书资料费 | `*印刷品*图书` |
| 通信费 | `*电信服务*` |
| 停车费 | `*停车费*非税票据`（北京市非税收入票据） |
| 其他 | 以上均不匹配 |

> 归类顺序很关键：先匹配「住宿」「铁路」「交通运输服务」「航空运输/机票」等更具体的，再匹配「餐饮/奶茶/饮品」等泛词。脚本里的 `classify()` 已按此顺序排好。

## 标准流程

1. **准备数据**：把识别好的发票整理成 JSON 数组，每项字段：
   ```json
   {
     "content": "*餐饮服务*餐饮费",
     "number": "26112000001956652561",
     "category": "电子发票（普通发票）",
     "taxid": "91110105664641441Q",
     "amount": "30.30"
   }
   ```
   - `amount` 必须用**字符串**存，避免浮点误差。
   - 非税票据（停车费）无发票号码/税号，`number`、`taxid` 填空字符串 `""`，`category` 写「北京市非税收入票据」。

2. **运行脚本**（两种模式）：

   **模式 A：直接出表**（数据已是 JSON）
   ```bash
   python3 <skills>/xk-invoice-ledger/scripts/build_ledger.py <数据.json> <输出.xlsx> [购买方抬头]
   ```

   **模式 B：目录遍历 + 出表**（推荐，可交叉校验是否有遗漏）
   ```bash
   python3 <skills>/xk-invoice-ledger/scripts/build_ledger.py --scan <目录> <数据.json> <输出.xlsx> [购买方抬头]
   ```
   - `--scan <目录>`：递归扫描目录下各子目录的 `tu/*.jpg`，打印每个子目录的图片数，并比对「图片总数 vs 数据条数」；若不一致会打印 ⚠️ 提示，帮助发现遗漏或多计。
   - `<购买方抬头>` 可选，填入后明细表的「购买方抬头」列统一显示该抬头。

3. **写入 AIGC 合规标识**（生成新工作簿必须）：
   ```bash
   python3 <workbuddy-sheet-generation>/scripts/aigc_label.py <输出.xlsx> --platform WORKBUDDY
   ```

4. **汇报**：讲清楚每个报销科目的张数与金额、总计、以及需要人工注意的点（如非税票据、混合归类、扫描校验发现的差异）。

5. **（可选）按科目归档图片**：需要把发票图片按报销科目分到子目录时：
   ```bash
   python3 <skills>/xk-invoice-ledger/scripts/organize_invoices.py <数据.json> <目录> [--extra <映射.json>]
   ```
   - 在 `<目录>` 下生成 `invoice/`，按报销科目建子目录，把每张发票图片**拷贝**（不改动原文件）到对应子目录。
   - 归类判定优先级：① 文件名里任一 8~20 位数字段命中数据里的发票号 → ② `--extra` 映射表（文件名 → 真实发票号）→ ③ 文件名关键字（滴滴/网约、停车/非税、机票/行程单、高铁/铁路）→ ④ 目录语义兜底。
   - **推荐用法**：先不传 `--extra` 跑一遍，脚本会打印「待人工归类」清单（归入「其他」的图片，通常是文件名不含发票号、或文件名数字是流水号/行程单号而非发票号）；对这些图片用视觉识别出真实发票号，写成 JSON 映射（`{"文件名.jpg": "发票号码"}`）再通过 `--extra` 传入重跑即可全部归位。
   - 脚本结束会打印各科目张数；若仍有「其他」会给出待核对清单。

## 关键坑（务必遵守）

- **金额用字符串**：JSON 里 `amount` 一律字符串（如 `"30.30"`），脚本内部用 `Decimal` 累加，禁止 float 直接相加。
- **合计写静态数值，不写公式**：避免依赖 Excel/预览器重算（本机无 LibreOffice，公式会显示异常），直接写已算好的数值。
- **非税票据单独归类**：停车费等非税票据不是增值税发票，无税号，归到「停车费」科目并在明细里标注「北京市非税收入票据」，不要混进增值税发票类别。
- **机票行程单单列**：航空运输电子客票行程单金额口径是「票价+基金+燃油」，与增值税发票「价税合计」不同，归「交通费-机票」单独统计。
- **目录混入的票**：识别时按发票实际内容归类，不要按所在文件夹归类（如「图书」文件夹里混着电信发票，应归通信费）。
