# 发票图片批量识别与汇总 — 使用说明

## 这个技能是干什么的

给一个装满发票图片的目录，自动完成：

1. 识别每张发票的 **金额（价税合计）、发票号码、发票内容、发票类别、购买方抬头、购买方税号**
2. 汇总所有发票金额，并**记录每一步累加的中间结果**，可逐笔复核
3. 检查有没有 **重复发票**（按发票号码判定）
4. 核对 **抬头是否都是指定公司、税号是否一致**
5. 按类别统计金额，生成 **发票台账表格**
6. 输出一份 Excel 报告，保存到指定目录

## 怎么用

直接对助手说，例如：

> 读取 `/Users/xxx/Desktop/发票` 目录下的所有发票图片，统计每张金额和汇总金额，检查是否有重复发票，核对抬头是不是「北京云测信息技术有限公司」、税号是不是「91110105664641441Q」，按类别统计，最后生成一张发票表格（含发票内容、发票号码、发票类别、购买方税号、价税合计），结果保存到同一目录。

助手会自动走「识别 → 计算 → 出表」全流程。

## 你会得到什么

一份 **`发票汇总报告.xlsx`**，里面 4 个工作表：

| Sheet | 内容 |
|---|---|
| 全部发票明细 | 每张票的发票内容、号码、类别、抬头、税号、价税合计，末尾有合计行 |
| 分类统计 | 按发票类别归类的张数与小计金额 |
| 汇总计算过程 | 从第 1 步到第 N 步的逐步累加过程，方便核对 |
| 核对与说明 | 张数、总额、是否重复、抬头/税号是否一致、非发票文件说明 |

同时对话里会给出：
- 逐张金额表 + 汇总总额
- 重复发票结论
- 抬头/税号一致性结论
- 分类统计表

## 需要注意的几个点

1. **金额精度**：用高精度数值计算，保留 2 位小数，不会出现浮点误差。
2. **重复判定只看发票号码**：两张金额相同不等于重复。
3. **税号不一致会如实标出**：如果某张发票税号和别的不同（例如一张是 `91110108MA018UFQ1Y`、其余是 `91110105664641441Q`），报告会标黄并提醒你人工复核，**不会擅自帮你改**。
4. **支付截图不是发票**：目录里如果有微信/支付宝的「支付成功」截图，会被单独标出，**不计入发票汇总**（它没有发票号码、税号等要素）。

## 高级用法（脚本直接跑）

如果你已经有识别好的结构化数据，可以跳过识别，直接跑汇总脚本：

```bash
python3 scripts/summarize.py 发票数据.json 输出目录 北京云测信息技术有限公司 91110105664641441Q
```

- `发票数据.json` 格式见 `assets/示例发票数据.json`
- 传「期望抬头」「期望税号」后，脚本会自动核对并标 ✅/⚠️
- 依赖 `openpyxl`（生成 Excel 用）；未装则仍会在控制台打印全部统计结果，只是不生成 Excel

## 字段口径

| 字段 | 说明 |
|---|---|
| 发票内容 | 发票「货物或应税劳务名称」，如 `*生产生活服务*餐费` |
| 发票号码 | 发票右上角号码 |
| 发票类别 | 电子发票（普通发票）/ 专用发票 等 |
| 购买方抬头 | 购买方名称 |
| 购买方税号 | 18 位纳税人识别号 |
| 价税合计 | 发票底部小写金额 |
