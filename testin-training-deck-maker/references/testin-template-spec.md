# Testin 模板规格

仅在触发 `testin-training-deck-maker` 后阅读本文件。

## 默认模板资产

- 默认内置模板：[../assets/Testin模板.pptx](../assets/Testin模板.pptx)

如果用户提供了另一个 Testin 品牌 `.pptx`，必须先检查用户提供的模板，并以该模板的实际检查结果为准。

## 模板页族

统一使用以下页族：

1. 封面页
2. 目录页
3. 蓝色分节页
4. 带左侧标题竖条和右上角 logo 的正文页

## 正文页锚点坐标

除非检查到的新模板有不同母版，否则 Testin 正文页使用以下坐标：

- 标题蓝色竖条：`left 36.36 top 25.88 width 8.64 height 32.92`
- 正文标题：`left 46.72 top 25.88 width 625.92 height 34.87`
- 正文副标题/辅助说明：从正文标题相同的左边缘开始
- 右上角 logo：`left 840 top 22.45 width 99.26 height 26.67`

## 模板匹配字号

以下是导出的 PowerPoint 目标字号，不是脚本里随意估算的字号。生成脚本必须严格使用本表字号；不得自行新增、近似或把 px 数字当作 pt 字号使用。

- 封面标题：`28pt`
- 封面副标题：`16pt`
- 封面日期/汇报人：`14pt`
- 目录标题：必须检查模板并完全匹配；默认 `Testin模板.pptx` 使用 `微软雅黑 24pt` 加粗白字，居中放在左上角蓝色标题块内
- 目录项：必须检查模板并完全匹配；默认 `Testin模板.pptx` 使用 `微软雅黑` `18pt`，在右侧目录列表中左对齐
- 分节页标题：必须检查模板并完全匹配；默认 `Testin模板.pptx` 使用 `微软雅黑` `32pt` 加粗白字，居中
- 正文页标题：必须检查模板并完全匹配；默认 `Testin模板.pptx` 使用 `微软雅黑` `16pt` 加粗，左对齐，坐标为 `left 46.72 top 25.88 width 625.92 height 34.87`
- 正文页副标题/辅助说明：`10pt`
- 正文页强调标题：根据强调程度使用 `12pt`、`14pt` 或 `16pt`
- 正文页内容：保持在 `9pt`、`12pt`、`14pt`、`16pt`、`18pt` 内

除非检查到的模板确实要求，否则不要给正文内容引入其他字号。不要近似处理目录页、分节页或正文标题字体；要保留或克隆模板文本框的 run 级别样式。

## artifact-tool 字体注意事项

写入文本样式时使用：

- `typeface: "微软雅黑"`

不要依赖 `fontFace`。

字号必须使用明确的 PowerPoint 点数。使用 artifact-tool 时不要把 numeric `fontSize` 当成 pt；numeric `fontSize` 是 px，可能导出为 13.5pt 等非规范字号。优先使用 structured run 的 `fontSize: "18pt"`、`fontSize: "16pt"` 等带 `pt` 单位的写法，或使用能明确表达点数的 API。

如果导出的 PPTX 或渲染结果没有显示预期字号，应检查生成后的 slide XML，再按本文件的 PowerPoint 目标字号修正脚本。目录项、分节标题、正文标题和正文内容都必须落在本文件列出的字号内；发现 13.5pt、10.5pt 等未列入字号时，必须视为 QA 失败并重新导出。

## 前三页

前三页必须严格遵循模板页族：

- 封面：使用真实模板背景、居中 logo、居中标题组、居中日期/汇报人
- 目录：使用真实模板背景，左上角蓝色目录标题块，右侧目录项，并保持 `目录` 标题和目录项的模板字体
- 分节：使用蓝色整页分节背景，右上角白色 Testin logo，并保持分节标题的模板字体

## 第 6 到第 10 页参考建议

以下内容类型在此模板体系中表现较好：

- 路径/策略页：三步横向路径，中间里程碑可适度强调
- 定义页：一个主蓝色指标/定义块，搭配少量辅助说明块
- 团队/使命页：平衡的 2x2 或 3 列布局，一个主蓝色块即可

避免：

- 用很窄的卡片承载很长的一行标题
- 添加源内容中没有的装饰性页脚口号
- 多个相邻页面重复完全相同的卡片堆叠

## 质量检查清单

交付前执行以下检查：

- 页数符合用户要求
- 备注为空
- 没有未处理占位符
- 没有旧模板残留文本，例如：`证券信创|柜台|国联|恒生|XX证券|单击此处|项目正式启动|通达信|券商|国金`
- 封面、目录、分节页和正文页标题对齐保持稳定
- 目录页和分节页文本 run 与检查到的模板完全一致，包括字体、字号、加粗状态、颜色、对齐方式和坐标
- 正文页标题文本 run 与检查到的模板完全一致，包括字体、字号、加粗状态、颜色、对齐方式和坐标
- 正文页内容字号保持在 Testin 正文字号集合内；该检查不包含正文标题
- 不允许出现由 px 换算导致的非规范字号，例如目录项或正文内容导出为 `13.5pt`、`10.5pt`
- 所有新写入文本都导出为 `微软雅黑`
- 覆盖同一个 PPTX 路径时，不要并行构建和渲染；必须先完成导出，再开始渲染
- 如果 slide XML 和渲染 PNG 不一致，优先相信刚导出的 PPTX/XML，并按顺序重新渲染
